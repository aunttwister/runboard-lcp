Boxes — per-Spark telemetry …

boxroleGPU temp °Cpower Wutil % clock MHzmem free GBexporter
Two GB10 boxes serve one engine in parallel (TP=2), so each runs its own monitoring container — monitor/ in this repo — serving the same exporter on :9400. The board reads the PAIR, not only the box it happens to run on: a one-box view reports half the machine as though it were the whole, and the unseen half is where a thermal event hides. Temp is coloured at 82 °C (warn) and 85 °C (critical — the pair's published shutdown zone); it is the only coloured value on this page, because it is the only one anybody acts on. A box that does not answer shows a dash, never a zero, because 0 °C on an unreachable Spark reads exactly like a cold one.
